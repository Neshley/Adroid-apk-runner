# 📱 APK Runner - Installation Guide

## 📥 How to Install

### Method 1: Using the Installer (Recommended)

1. **Download** the `APKRunner_v1.0.zip` file
2. **Extract** the ZIP file to any folder
3. **Right-click** on `installer.bat`
4. Select **"Run as Administrator"**
5. Follow the on-screen prompts
6. **Done!** APK Runner is now installed

**After installation:**
- 🖥️ Desktop shortcut created
- 📂 Start Menu entry added
- 🗑️ Uninstaller available in Control Panel

### Method 2: Portable (No Installation)

1. **Download** `APKRunner.exe`
2. **Double-click** to run
3. No installation needed!

### Method 3: Run from Source

```bash
# Clone repository
git clone https://github.com/Neshley/apk-runner.git
cd apk-runner

# Run the app
python src/apk_runner.py
